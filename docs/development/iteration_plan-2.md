## 設計

### Java 版の特徴

Ruby 版との主な違い:

| 観点 | Ruby | Java |
|------|------|------|
| インターフェース | Duck Typing（暗黙的） | `interface`（明示的） |
| 抽象クラス | `raise NotImplementedError` | `abstract class` / `abstract method` |
| Strategy | ブロック / Proc | `interface` + ラムダ式（Java 8+） |
| Iterator | `Enumerable` + `each` | `Iterable<T>` + `Iterator<T>` |
| Decorator | `extend` + Module | クラスベースのみ |
| Proxy | `method_missing` | `java.lang.reflect.Proxy`（動的プロキシ） |
| Singleton | `Singleton` モジュール / Module | `enum` Singleton（Effective Java 推奨） |
| Builder | `method_missing` DSL | 流暢なインターフェース（メソッドチェーン） |
