### Python 版の特徴

| 観点 | Ruby | Java | Python |
|------|------|------|--------|
| 型システム | Duck Typing | インターフェース | Duck Typing + 型ヒント |
| Strategy | ブロック / Proc | @FunctionalInterface + ラムダ | 関数（第一級オブジェクト） |
| Decorator | extend + Module | クラスベース委譲 | @decorator 言語構文 |
| Iterator | Enumerable + each | Iterable<T> | \_\_iter\_\_ / ジェネレータ |
| Observer | Observable モジュール | カスタムインターフェース | プロパティ + コールバック |
| Singleton | Singleton モジュール | enum | メタクラス / モジュール |
| Proxy | method_missing | 動的プロキシ | \_\_getattr\_\_ |
| Builder | method_missing DSL | 流暢なインターフェース | dataclass + ビルダー |
