# 多言語統合解説 - デザインパターンからはじめるプログラミング入門

## 概要

本セクションでは、14 言語で実装した 13 のデザインパターンを横断的に比較し、パターンの本質と各言語固有の表現を統合的に解説します。

個別言語の記事では「その言語でパターンをどう書くか」を学びました。ここでは視座を上げ、「パターンが解こうとしている問題は言語を超えて共通か」「言語の設計思想によってパターンの姿はどう変わるか」を探求します。

---

## 対象言語

14 言語を設計思想の軸で 5 カテゴリに分類します。

| カテゴリ | 言語 | 特徴 |
|---------|------|------|
| 動的 OOP | Ruby, JavaScript, Python, PHP | ダックタイピング、メタプログラミング、クロージャ |
| 静的 OOP | Java, TypeScript, C# | インターフェース、ジェネリクス、抽象クラス |
| システム言語 | Go, Rust | 継承なし、構造的型 / トレイト、ゼロコスト抽象化 |
| 関数型（JVM / .NET） | F#, Clojure, Scala | 判別共用体、プロトコル、型クラス |
| 関数型（VM / 純粋） | Elixir, Haskell | プロセスモデル、純粋関数、モナド |

## 読み方

本セクションは、個別言語の記事を少なくとも 2 つ以上読了してから取り組むことを推奨します。1 つの言語だけでは「比較」の視点が得られず、本セクションの価値が半減します。

推奨の読み順:

1. **Ruby 編** を通読する（源流であり、全パターンの動機が最も平易に書かれている）
2. **自分のメイン言語** の編を通読する
3. **本セクション** で横断比較を行う
4. 興味のある他言語の編を拾い読みする
