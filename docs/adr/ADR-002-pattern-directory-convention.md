# ADR-002: パターンごとのディレクトリ分割（章番号 + パターン名）

## ステータス

承認

## コンテキスト

13 パターンの実装コードをどのように配置するか決める必要がある。選択肢は以下の通り。

1. フラットに `lib/` と `test/` に全ファイルを配置
2. パターンごとにディレクトリを分割

## 決定

**章番号 + パターン名のディレクトリ**に分割する。

```
apps/ruby/design-pattern/
├── 04-template-method/
│   ├── lib/
│   └── test/
├── 05-strategy/
│   ├── lib/
│   └── test/
...
└── 16-interpreter/
    ├── lib/
    └── test/
```

### 命名規則

- ディレクトリ名: `{章番号2桁}-{パターン名ケバブケース}/`
- 実装ファイル: `lib/{パターン名スネークケース}.rb`
- テストファイル: `test/{パターン名スネークケース}_test.rb`

### 共通テストヘルパー

`test/test_helper.rb` をプロジェクトルート�� 1 つ配置し、各テストから `require_relative "../../test/test_helper"` で参照する。

## 影響

- 後続 13 言語でも同じディレクトリ構成を踏襲する（`apps/{lang}/design-pattern/{NN-pattern}/`）
- パターンごとに独立しているため、個別にテスト実行が可能
- Rake の `FileList["**/test/**/*_test.rb"]` で全テストを一括実行できる
